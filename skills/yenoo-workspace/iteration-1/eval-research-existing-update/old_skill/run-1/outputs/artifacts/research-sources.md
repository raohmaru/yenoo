# Research sources

- [WebAssembly Component Model documentation](https://component-model.bytecodealliance.org/) — overview of typed component composition.
- [WIT reference](https://component-model.bytecodealliance.org/design/wit.html) — language-neutral interface definitions and types.
- [Component Model design and specification](https://github.com/WebAssembly/component-model) — current standardization status and WASI Developer Preview milestones.
- [WebAssembly System Interface](https://github.com/WebAssembly/WASI) — WASI 0.2's WIT-based APIs and WASI 0.3's component-model async functionality.
